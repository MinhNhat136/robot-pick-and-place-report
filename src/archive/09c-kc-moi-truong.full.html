Truy cập server qua Teleport

Máy chủ dùng chung với nhóm khác, nên làm việc trong thư mục và phiên tmux riêng.

BƯỚC 1
Đăng nhập Teleport
tsh login theo tài khoản được cấp
BƯỚC 2
Vào server
tsh ssh root@pet-poc-gpu-vm
BƯỚC 3
Kiểm tra môi trường
Commit, CUDA, GPU rảnh, ổ đĩa
BƯỚC 4
Mở tmux riêng
Server chạy lâu, không mất khi ngắt SSH
# máy trạm
tsh login --proxy=<teleport-proxy> --user=<tài-khoản>     # [xác nhận proxy và tài khoản được cấp]
tsh ssh root@pet-poc-gpu-vm

# trên server
cd /root/shimizu/Isaac-GR00T
git log --oneline -1          # 4b1dca9 Readme Updates and Total Task Correction.
uv run python -c "import gr00t, torch; print('GR00T ok | CUDA', torch.cuda.is_available(), torch.cuda.get_device_name(0))"
nvidia-smi                    # GPU phải rảnh; có job của người khác thì chờ
tmux new -s verify            # thoát tạm: Ctrl-b d · vào lại: tmux a -t verify
Quy ước dùng chung: không sửa ~/.bashrc, không dùng phiên tmux của người khác (vd. g1train), không ghi đè file trong /root/shimizu/workspace/. Biến môi trường để trong file riêng, vd. /root/shimizu/hammer_env.sh.

Cài client trên máy trạm

Package standalone_g1_gr00t cần hai môi trường: .venv (Python 3.10, cho kiểm thử và notebook không mô phỏng) và Python của Isaac Sim (cho notebook có mô phỏng).

cd ~/workspace/shimizu-robot/codes/standalone_g1_gr00t

# môi trường .venv
make venv            # uv venv .venv --python 3.10, cài package + dev + notebook
make sync            # copy 4 file YAML khớp/WBC từ ~/IsaacLab-Arena, ghi hash nguồn
make assets          # tải policy chân AGILE (ONNX) vào assets/wbc/
make test            # unit test không cần mô phỏng

# môi trường Isaac Sim
make sim-install     # cài package vào ~/isaac-sim-6/python.sh
make sim-test        # kỳ vọng: 64 passed, 7 skipped
make sim-test-scene  # test có scene (robot đứng vững, bàn/táo/đĩa), ~3,5 phút
make sim-kernel      # đăng ký kernel Jupyter "isaacsim6" cho notebook mô phỏng

Cài server (khi dựng máy mới)

pet-poc-gpu-vm đã cài sẵn. Chỉ làm bước này khi dựng lại trên máy chủ khác.

git clone https://github.com/NVIDIA/Isaac-GR00T.git /root/shimizu/Isaac-GR00T
cd /root/shimizu/Isaac-GR00T && git checkout 4b1dca9d88d2a0b9ea5a65aa61c82ff89f5c4f0e
# tạo môi trường uv theo README của Isaac-GR00T, rồi kiểm tra:
uv run python -c "import gr00t, torch; print(torch.cuda.is_available())"

# đẩy checkpoint từ máy trạm lên server (rsync chạy tiếp được nếu bị ngắt)
rsync -avP -e "tsh ssh" <thư-mục-checkpoint> root@pet-poc-gpu-vm:/root/shimizu/models/<kịch-bản>/
Modality config phải khớp lúc huấn luyện: kịch bản 1 và 3 dùng g1_sim_wbc_data_gr00t_n_1_7_config.py của Arena; kịch bản 2 dùng groot/g1_dex3_joint_sim_config.py trong codes/g1_real2sim. So md5 hai phía trước khi chạy.
