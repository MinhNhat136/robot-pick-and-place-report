Khởi động server

Chạy trong tmux trên server. Cổng chỉ mở sau khi model nạp xong (khoảng một phút); trước đó client sẽ báo hết giờ.

tsh ssh root@pet-poc-gpu-vm
tmux new -s verify
cd /root/shimizu/Isaac-GR00T
uv run python gr00t/eval/run_gr00t_server.py \
  --modality-config-path <modality-config theo bảng trên> \
  --model-path <checkpoint theo bảng trên> \
  --embodiment-tag NEW_EMBODIMENT \
  --device cuda --host 127.0.0.1 --port <5556 | 5557>
# sẵn sàng khi in: Server is ready and listening on tcp://…:<cổng>

Lối tắt cho kịch bản búa

Script có sẵn nạp checkpoint theo số bước, chạy server trong tmux hammer:srv, cổng 5557:

tsh ssh root@pet-poc-gpu-vm '/root/shimizu/models/static_hammer/switch_ckpt.sh 10000'
# đổi checkpoint khác: switch_ckpt.sh 2000 | 4000 | 6000 | 8000 | 10000
