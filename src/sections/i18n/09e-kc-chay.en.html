Results shipped in the package will be overwritten: make sim-nbXX writes new output into the .ipynb file itself; nb07 also appends to data/runs_galileo.jsonl and overwrites the videos data/videos/gr00t_galileo/epN.mp4. Error when Isaac Sim shuts down: at the end of each run you may see Segmentation fault and make: *** Error 1. If the line [inproc] wrote notebooks/… | ok=True appeared before that, the notebook finished and the results were fully written.

Hammer at-rest threshold: nb12 currently treats the hammer as at rest when its velocity is < 0.02 m/s and its angular velocity < 0.12 rad/s (variables LIN_VEL_TH, ANG_VEL_TH in §3). MATCHES THE REPORT
Within the confidence interval

Each episode is randomized; with 50 episodes a difference of about ±13 percentage points is normal, with 100 episodes about ±9 points.

TECHNICAL ERRORS
Not counted in the rate

Failed episodes (server timeout, lost connection) are logged with the reason and excluded from the success rate; the notebook stops if the server does not respond again.

RESUME
No need to start over

nb10 and nb12 skip episodes already present in the results folder; restart the server and re-run the same command.
