用語

VLA画像と言語を入力とし、ロボットの制御指令を直接出力するモデル
Foundation model大規模データで事前学習したモデル。少量のデータで特定タスク向けにファインチューニングする
Embodiment特定のロボットの身体の種類（関節、カメラ、手）
Action chunk1 回の推論でモデルが返すアクション列（40 ステップ = 50 Hz で 0.8 s）
Flow matching / DiTノイズを段階的に除去して連続データを生成する手法。アクション列の生成に使う
Teleop人がロボットを遠隔操作して（VR ヘッドセット）見本データを作成すること
Open-loop / closed-loop記録済みデータでの評価 / モデルが自ら連続して制御する評価
Real2sim実世界のデータをシミュレーションに移すこと
Domain gap学習環境と実行環境の違い
Visual gap実行時のシーンの見た目がデータ記録時と異なると、モデルの成功率が低下する現象（リンゴのタスク 92 → 56 → 0 %）
Domain randomizationシミュレーション内で照明、材質、背景、カメラ角度をランダムに変え、モデルが 1 つのシーンを丸暗記しないようにする手法
Demo generation既存のテレオペデモ（時間、開始点、把持、解放）を変形してシミュレーションで再実行し、成功したデモだけを残す手法（MimicGen の方式）
FK / IK順運動学：関節角度から手の位置を計算する。逆運動学：目標位置から関節角度を計算する
PD 制御器比例 – 微分：トルク = Kp × (目標角度 − 現在角度) − Kd × 関節速度。減衰付きのばねのように関節を目標へ引き戻す
Rate limiter制御ステップ（20 ms）ごとに、関節指令が前回の指令から変化できる量を一定のしきい値までに制限する（腕 0.2 rad、腰 0.1 rad、手 1.5 rad）
WBC / AGILE全身制御器。AGILE は G1 の脚のバランスを保つ
Wilson 95 %成功率の信頼区間。試行回数が少ない場合に適する
MAE平均絶対誤差
