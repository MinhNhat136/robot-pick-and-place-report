    • self_built_scene_50ep/ — self-built scene: 0/50

README.md at the top level summarises the results and origin of each run. Common files in each run: episodes.jsonl (one line per attempt), summary.json / summary.md (success rate, confidence interval, failure classification), videos …_success.mp4 / …_fail.mp4.

06assets/ — Simulation assets
Location: ~/workspace/shimizu-robot/assetsThe source code reads from this path
  • nucleus_cache/ — offline copy of the NVIDIA files Isaac Lab downloads when building a scene: the Galileo background, the hammer_2 hammer, the red bin, the G1 robot and the lower-body controller model (WBC). With it, runs need no network; without it, Isaac Lab downloads them again.
  • objects/objaverse/apple_01.usd, objects/hot3d/clay_plates.usd — the apple and plate for the apple → plate scenario in the standalone pipeline.

The 4-fruit real2sim scenario does not use this folder (the robot URDF is in codes/g1_real2sim/assets/).
