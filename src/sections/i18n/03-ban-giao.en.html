Where to start

Three paths by purpose, from simple to complete.

PATH 1
View the results
  1. Open 01_bao_cao/index.html
  2. Read the Overview section and the three scenarios
  3. Watch the videos in 05_ket_qua_danh_gia
Needs: a browser · ~30 min
PATH 2
Re-run the evaluation
  1. Install Isaac Sim 6.0.1, Isaac Lab 3.0-beta2 and the standalone_g1_gr00t environment
  2. Run the GR00T server on a GPU machine with the checkpoint from card 4
  3. Run evaluation notebook nb10 (4 fruits) or nb12 (hammer), headless
Needs: GPU workstation + GPU server (section I.02)
PATH 3
Teach the robot a new task
  1. Build the environment and collect demos via teleop (arena_bua_thung)
  2. Generate more demos, convert to LeRobot
  3. Fine-tune GR00T following the guide in 06_tai_lieu
  4. Evaluate with the notebooks as in path 2
Reference: the hammer task took ~6 days from start to results
